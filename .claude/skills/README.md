# Skills Index

## Available Skills

| 技能名称 | 文件 | 描述 |
|---------|------|------|
| 一键上新 | `product-launch.md` | 当用户上传产品照片并发送"上新#数量"时触发，自动完成产品信息录入、图片处理、数据写入、器官大人映射全流程。 |

## Usage

当用户发送"上新#数量"时，读取 `product-launch.md` 技能文件并按照执行流程执行。

## Skill File Format

每个技能文件应包含：
1. **触发条件**：描述何时调用该技能
2. **执行流程**：详细的步骤说明
3. **数据模板**：标准的数据结构
4. **禁止事项**：必须遵守的约束
