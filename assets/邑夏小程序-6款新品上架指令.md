## ⛔ 执行铁律

1. 修改已有文件用 edit_file 精确替换，禁止 write_file 覆盖
2. 葡萄是替换（同ID prod_grape_001），其他5款是新增（新ID）
3. 旧产品（桃你欢心/楂香四溢/大吉大梨/似水榴年）全部保留不动
4. 图片路径必须与实际文件名一致（已放在 src/assets/images/products/yixia-new/）
5. 每改完一个文件 grep 确认无误
6. 全部改完后执行 pnpm validate + pnpm build:weapp
7. 构建成功后 git add -A && git commit -m "feat: 6款品夏新品上架+产品图+场景图+文案" && git push
