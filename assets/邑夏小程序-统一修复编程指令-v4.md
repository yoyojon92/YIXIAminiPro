## ⛔ 执行铁律（必读，不可压缩不可省略）

以下规则优先级高于一切。违反任何一条即为执行失败。

### 铁律1：禁止说而不做
- **禁止**在回复中说"我已修改了XXX"但实际文件未写入。每声称一个操作，必须真实执行write_file/edit_file/bash写入。
- **禁止**用注释占位符代替实际实现。如 `// TODO`、`/* 待对接API */`、`暂不实现` 均禁止出现。
- **禁止**只改了import但不用、只声明了interface但不实例化、只写了函数签名但函数体是空的。

### 铁律2：禁止上下文压缩导致功能丢失
- 本文档中每一个模块、每一个页面、每一个Store都必须完整实现，不允许因为"篇幅限制"跳过任何一个。
- 如果你觉得输出会超限，应该按模块分步写入文件，而不是把某个模块压缩成"参照上面类似实现"。
- 每个页面的Mock数据必须能渲染出完整UI，不允许出现空白卡片、空列表、占位文字。

### 铁律3：禁止伪完成
- **禁止**创建路由但目标页面不存在。app.config.ts注册了路径，则对应tsx必须真实创建。
- **禁止**修改了profile页面的跳转路径但新路径对应的页面不存在。
- **禁止**在Store中声明了方法但页面不调用、或页面import了Store但Store方法未定义。

### 铁律4：验证清单（执行完必须逐项自检）
每完成一个模块，必须对照以下清单自检并输出结果：
```
[ ] 页面文件已创建且内容完整（非空文件）
[ ] 页面config.ts已创建
[ ] app.config.ts已注册该页面路径
[ ] Store文件已创建且所有声明的方法都有完整实现体
[ ] 页面中import的组件在项目中存在
[ ] 页面中import的Store方法在Store中有定义
[ ] Mock数据足够渲染出完整UI（无空白卡片、空列表）
[ ] 路由跳转目标页面存在（不会跳到404或错误页面）
[ ] 所有页面的navigationBarTextStyle为'white'
[ ] tabBar页面的跳转使用switchTab，非tabBar页面使用navigateTo
```

### 铁律5：文件粒度操作
- 每个文件单独一次write_file/edit_file调用，不要把多个文件内容拼在一次调用里。
- 修改已有文件时必须先read_file确认当前内容，然后用edit_file精确替换，不要整个文件覆盖。

### 铁律6：tabBar页面禁止使用navigateTo ⚠️最高优先级
- 微信小程序中，**tabBar页面只能用`Taro.switchTab()`跳转，禁止用`navigateTo`或`router.push()`**
- 当前tabBar页面列表（来自app.config.ts）：首页(index)、分类(category)、购物车(cart)、我的(profile)
- **switchTab不支持URL参数**，需要通过全局Store传递参数（如分类ID）
- 非tabBar页面之间可以正常使用navigateTo/router.push传参

### 铁律7：微信小程序审核合规 ⚠️新增
- 所有页面内容必须通过微信小程序审核标准
- 禁止出现：诱导分享、强制关注、虚拟商品购买（未报备）、未授权收集用户信息、过度索权
- 禁止出现："分享得优惠券""邀请好友得XX""关注公众号"等诱导关注/分享文案
- 社交功能（加好友、私信）必须在审核时隐藏，不可在用户端直接展示
- 酒类商品页面必须有"未成年人禁止饮酒"提示
- 所有用户数据获取需模拟用户授权流程

## 🔍 逻辑错误根因分析（必读，不可跳过）

### 错误1：首页分类图标点不开 ⚠️最高优先级 已报3次未修复
**现象**：首页点击"果酒系列"/"粮食酒系列"/"NFC果汁系列"/"礼盒套装"图标，无法跳转到分类页，控制台报错 `navigateTo:fail can not navigateTo a tabbar page`。
**根因**：分类页（category/index）是tabBar页面，但首页代码用了 `router.push({ url: '/pages/category/index?category=fruit_wine' })`，相当于`navigateTo`。微信小程序禁止`navigateTo`跳转tabBar页面，必须用`switchTab`。但`switchTab`不支持URL参数（`?category=fruit_wine`），所以分类ID传不过去。
**额外问题**：首页搜索栏也用了 `router.push({ url: '/pages/category/index' })`，同样报错。
**修复策略**：
1. 新建`categoryStore.ts`，用Zustand存储用户点击的分类ID
2. 首页点击分类时：先`categoryStore.setSelectedCategory('fruit_wine')`，再`Taro.switchTab({ url: '/pages/category/index' })`
3. 首页搜索栏：也改为`Taro.switchTab({ url: '/pages/category/index' })`，不传参
4. 分类页`useDidShow`生命周期中读取`categoryStore.consumeSelectedCategory()`，据此筛选产品

### 错误2：分类页使用旧分类体系
**现象**：分类页(categories)有"气泡酒""限定款"等不存在的分类，产品也是占位Mock。
**根因**：category/index.tsx 里的 categories 和 products 是本地硬编码的旧数据，没有使用统一的 UNIFIED_CATEGORIES 和 MOCK_PRODUCTS。
**修复策略**：整个分类页重写，使用 UNIFIED_CATEGORIES + MOCK_PRODUCTS。

### 错误3：会员权益展示过多层级
**根因**：当前显示多级会员（月卡/季卡/年卡等），用户要求只显示第一级（月卡会员）。
**修复策略**：会员权益只保留月卡会员相关内容。

### 错误4：我的画像中"消费行为"标签不合规
**根因**：画像中"薅羊毛达人"等消费行为标签涉及用户消费画像，微信审核可能判定为过度收集用户行为数据。
**修复策略**：移除"消费行为"标签分类，只保留"口味偏好"和"身份标签"。画像中只显示用户在小程序发布的blog内容统计。

### 错误5：社交属性（加好友）暴露在用户端
**根因**：送酒员页面有"加好友"等社交功能入口，微信审核对小程序社交功能管控严格。
**修复策略**：用户端移除所有社交属性入口（加好友、私信、关注等）。选中送酒员后，送酒员端通过小程序消息触达+埋点通知，但用户端不展示社交UI。

### 错误6：跑腿员中心两个空白卡片
**根因**：Coze生成了flex容器但跳过了卡片内部内容实现。
**修复策略**：整体重写runner-center页面。

### 错误7：profile页面"支付方式"跳转到订单页面
**根因**：toolItems的path全部指向`/pages/orders/index?tab=xxx`，orders页面只处理了订单tab。
**修复策略**：每个功能独立页面。

### 错误8：产品详情页永远显示同一个产品
**根因**：硬编码了productDetail。
**修复策略**：根据URL的id参数动态加载。

### 错误9：产品详情页"配送方式"模块无功能
**修复策略**：直接删除，留到下单结算流程。

### 错误10：深色导航栏/顶部栏文字不可见
**根因**：顶部渐变区域文字用了深色class，与深色背景融为一体。
**修复策略**：所有顶部渐变区域内文字必须用`text-white`/`text-white/70`/`text-white/50`。所有config.ts的`navigationBarTextStyle`必须为`'white'`。

### 错误11：诱导分享/关注文案不合规
**根因**：profile页面底部有"分享邀请好友，邀请新用户可得优惠券"，activity页面有"邀请好友下单双方都有优惠"，属于微信审核禁止的诱导分享。
**修复策略**：移除或改为中性文案。

## 模块一：分类跳转核心修复 ⚠️最高优先级

### 新建 src/store/categoryStore.ts

这是解决"点不开分类页面"的核心。因为category是tabBar页面，switchTab不支持URL参数，所以必须用Store跨页面传递分类ID。

```ts
/**
 * 分类状态管理
 * 用途：从首页点击分类图标时，通过Store传递分类ID到分类页
 * 原因：category是tabBar页面，switchTab不支持URL参数，只能用全局Store传递
 */
import { create } from 'zustand'

export type UnifiedCategoryId = 'fruit_wine' | 'grain_wine' | 'nfc_juice' | 'gift_box'

interface CategoryState {
  /** 用户从首页选择的分类ID，null表示显示全部 */
  selectedCategory: UnifiedCategoryId | null
  /** 设置分类ID（首页点击分类时调用） */
  setSelectedCategory: (categoryId: UnifiedCategoryId | null) => void
  /** 读取并清除分类ID（分类页useDidShow时调用，读完后清空防止下次进入还自动选中） */
  consumeSelectedCategory: () => UnifiedCategoryId | null
}

export const useCategoryStore = create<CategoryState>()((set, get) => ({
  selectedCategory: null,

  setSelectedCategory: (categoryId) => {
    set({ selectedCategory: categoryId })
  },

  consumeSelectedCategory: () => {
    const { selectedCategory } = get()
    set({ selectedCategory: null }) // 读完后清空
    return selectedCategory
  }
}))
```

关键修改：
1. **使用`useDidShow`生命周期**读取Store中的分类ID（不是useEffect，因为tabBar页面每次显示都会触发useDidShow）
2. **调用`consumeSelectedCategory`**（读取后自动清空，防止下次进入还自动选中）
3. **使用统一分类**筛选产品（UNIFIED_CATEGORIES + MOCK_PRODUCTS）
4. **删除旧的硬编码categories和products**

```tsx
import { useState } from 'react'
import { View, Text, ScrollView } from '@tarojs/components'
import { useRouter } from '@tarojs/taro'
import { useDidShow } from '@tarojs/taro'
import { Card, CardContent } from '@/components/ui/card'
import { UNIFIED_CATEGORIES, UnifiedCategoryId, useCategoryStore } from '@/store/categoryStore'
import { MOCK_PRODUCTS, Product } from '@/mock/products'

export default function Category() {
  const router = useRouter()
  const [selectedCategory, setSelectedCategory] = useState<UnifiedCategoryId | 'all'>('all')
  const [searchValue, setSearchValue] = useState('')

  // ⚠️ 关键：useDidShow读取Store中的分类ID
  useDidShow(() => {
    const categoryId = useCategoryStore.getState().consumeSelectedCategory()
    if (categoryId) {
      setSelectedCategory(categoryId)
    }
  })

  // 分类筛选
  const filteredProducts = MOCK_PRODUCTS.filter(product => {
    const matchCategory = selectedCategory === 'all' || product.category === selectedCategory
    const matchSearch = searchValue === '' || product.name.includes(searchValue)
    return matchCategory && matchSearch
  })

  const goToProduct = (id: string) => {
    router.push({ url: `/pages/product/index?id=${id}` })
  }

  return (
    <View className="min-h-screen bg-gray-50 pb-safe">
      {/* 搜索栏 */}
      <View className="bg-white px-4 py-3 sticky top-0 z-50">
        <View className="flex items-center gap-3">
          <View className="flex-1 bg-gray-100 rounded-full px-4 py-2 flex items-center">
            <Text className="text-gray-400 text-sm">搜索果酒、果汁...</Text>
          </View>
        </View>
      </View>

      {/* 分类Tab */}
      <ScrollView scrollX className="bg-white px-4 py-2">
        <View className="flex gap-4">
          <View
            className={`px-4 py-2 rounded-full text-sm ${selectedCategory === 'all' ? 'bg-primary text-white' : 'bg-gray-100 text-gray-600'}`}
            onClick={() => setSelectedCategory('all')}
          >
            <Text className={selectedCategory === 'all' ? 'text-white' : 'text-gray-600'}>全部</Text>
          </View>
          {UNIFIED_CATEGORIES.map(cat => (
            <View
              key={cat.id}
              className={`px-4 py-2 rounded-full text-sm ${selectedCategory === cat.id ? 'bg-primary text-white' : 'bg-gray-100 text-gray-600'}`}
              onClick={() => setSelectedCategory(cat.id)}
            >
              <Text className={selectedCategory === cat.id ? 'text-white' : 'text-gray-600'}>
                {cat.icon} {cat.name}
              </Text>
            </View>
          ))}
        </View>
      </ScrollView>

      {/* 产品列表 */}
      <View className="px-4 mt-4">
        <View className="grid grid-cols-2 gap-3">
          {filteredProducts.map(product => (
            <Card key={product.id} onClick={() => goToProduct(product.id)}>
              <CardContent className="p-3">
                <View className="aspect-square bg-gray-100 rounded-lg mb-2 flex items-center justify-center">
                  <Text className="text-4xl">
                    {product.category === 'fruit_wine' ? '🍷' : product.category === 'grain_wine' ? '🥃' : product.category === 'nfc_juice' ? '🧃' : '🎁'}
                  </Text>
                </View>
                <Text className="text-sm font-medium text-gray-900">{product.name}</Text>
                <Text className="text-xs text-gray-500 mt-1">{product.subtitle}</Text>
                <View className="flex items-baseline gap-2 mt-2">
                  <Text className="text-lg font-bold text-red-500">¥{product.price}</Text>
                  {product.originalPrice && (
                    <Text className="text-xs text-gray-400 line-through">¥{product.originalPrice}</Text>
                  )}
                </View>
                <Text className="text-xs text-gray-400 mt-1">{product.alcohol} · {product.capacity}</Text>
              </CardContent>
            </View>
          ))}
        </View>
        {filteredProducts.length === 0 && (
          <View className="flex flex-col items-center py-10">
            <Text className="text-gray-400">暂无该分类产品</Text>
          </View>
        )}
      </View>
    </View>
  )
}
```
