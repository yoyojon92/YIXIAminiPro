# 邑夏小程序 - 礼盒图片替换

## ⚠️ 铁律：不要用AI生成任何图片！只改代码引用路径！不要修改/删除已有图片文件！

---

## 任务目标

替换两款礼盒的产品图片，使用用户提供的正式礼盒照片。

---

## 步骤1：下载礼盒图片到项目目录

在项目根目录执行PowerShell：

```powershell
New-Item -ItemType Directory -Path "src\assets\images\products\yixia-gift" -Force

# 果酒混合礼盒（4瓶装横图）
Invoke-WebRequest -Uri "https://www.coze.cn/s/AchBxIu_ozw/" -OutFile "src\assets\images\products\yixia-gift\gift-wine-box.png"

# 缤纷礼盒-果汁（8瓶装实物图）
Invoke-WebRequest -Uri "https://www.coze.cn/s/_uvfSkwP7i8/" -OutFile "src\assets\images\products\yixia-gift\gift-juice-box.png"
```

如果下载失败，用户需手动将图片放入 `src/assets/images/products/yixia-gift/` 目录，文件名分别为 `gift-wine-box.png` 和 `gift-juice-box.png`。

---

## 步骤2：修改 src/mock/products.ts

找到两款礼盒产品，修改 image 和 images 字段的路径：

### 缤纷礼盒（gift_juice_box）

```typescript
// 原来（占位图）
image: '/assets/images/products/yixia-juice/02-xian-tao.png',
images: ['/assets/images/products/yixia-juice/02-xian-tao.png', ...],

// 改为
image: '/assets/images/products/yixia-gift/gift-juice-box.png',
images: ['/assets/images/products/yixia-gift/gift-juice-box.png', '/assets/images/products/yixia-juice/01-xian-li.png', '/assets/images/products/yixia-juice/02-xian-tao.png', '/assets/images/products/yixia-juice/03-hong-pu-tao.png', '/assets/images/products/yixia-juice/04-bai-pu-tao.png'],
```

### 果酒混合礼盒（gift_wine_box）

```typescript
// 原来（占位图）
image: '/assets/images/products/yixia-wine/01-liu-hong-xin-shi.png',
images: ['/assets/images/products/yixia-wine/01-liu-hong-xin-shi.png', ...],

// 改为
image: '/assets/images/products/yixia-gift/gift-wine-box.png',
images: ['/assets/images/products/yixia-gift/gift-wine-box.png', '/assets/images/products/yixia-wine/01-liu-hong-xin-shi.png', '/assets/images/products/yixia-wine/02-pu-xiang-an-du.png', '/assets/images/products/yixia-wine/03-tao-xin-an-dong.png', '/assets/images/products/yixia-wine/04-qing-ping-wei-zui.png'],
```

---

## 步骤3：确认Taro copy配置

确认 `config/index.ts` 中 copy.patterns 已包含图片目录（之前的修复应该已经配好了）：

```typescript
copy: {
  patterns: [
    { from: 'src/assets/images/', to: 'dist/assets/images/' }
  ],
  options: {},
},
```

如果 patterns 仍为空，必须加上上面的配置，否则图片不到dist目录会500报错。
