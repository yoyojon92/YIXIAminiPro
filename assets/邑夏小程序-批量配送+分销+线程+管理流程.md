## 一、学校批量送货 + 成本挂钩货款比例调整

### 1.1 需求分析

| 需求 | 当前状态 | 目标 |
|------|---------|------|
| 学校批量送货 | 无 | 管理员发起批量订单，指定学校+楼栋，跑腿员统一配送 |
| 货款比例调整 | 无 | 按成本结构动态调整：原料成本→包装成本→配送成本→分销提成→利润 |
| 分销计入规则 | 无 | 校内自提=计入辅导员分销，邮寄=不计入 |

### 1.2 数据模型设计

#### 批量配送订单 BatchOrder

```typescript
interface BatchOrder {
  id: string
  schoolId: string
  schoolName: string
  targetBuilding: string[]        // 目标楼栋
  items: BatchOrderItem[]
  totalQuantity: number
  totalAmount: number
  status: 'pending' | 'delivering' | 'completed'
  assignedRunnerId?: string       // 指定跑腿员
  createdAt: string
  completedAt?: string
}

interface BatchOrderItem {
  productId: number
  productName: string
  quantity: number                // 批量数量
  unitPrice: number
  totalPrice: number
}
```

#### 成本比例模型 CostRatio

```typescript
interface CostRatio {
  id: string
  schoolId: string                // 按学校独立配置
  rawMaterialRatio: number        // 原料成本占比，默认0.35
  packagingRatio: number          // 包装成本占比，默认0.15
  deliveryRatio: number           // 配送成本占比，默认0.10
  distributionRatio: number       // 分销提成占比，默认0.10
  platformRatio: number           // 平台运营占比，默认0.10
  profitRatio: number             // 利润占比，默认0.20
  updatedAt: string
}
```

**计算逻辑**：
- 单瓶售价 = 成本 / (1 - 利润率 - 分销率 - 平台率 - 配送率)
- 管理员可在控制中心调整任意比例，系统自动重算建议售价
- 批量订单享受「配送率降50%」优惠（规模效应摊薄配送成本）

### 1.3 线上配送方式扩展

```typescript
// cartStore.ts - DeliveryType 扩展
export type DeliveryType = 'dormitory' | 'self_pickup' | 'mail'

export interface DeliveryInfo {
  type: DeliveryType
  // 宿舍配送
  dormitory?: string
  roomNumber?: string
  // 自提点
  pickupShopId?: string
  pickupShopName?: string
  // 邮寄
  mailAddress?: {
    name: string
    phone: string
    province: string
    city: string
    district: string
    detail: string
  }
  // ★ 分销标记
  distributionEligible: boolean   // 校内自提=true, 邮寄=false
}
```

### 1.4 分销计入逻辑

```
下单 → 选择配送方式
  ├─ 宿舍配送(dormitory) → distributionEligible = true  → 计入辅导员分销
  ├─ 校内自提(self_pickup) → distributionEligible = true → 计入辅导员分销
  └─ 邮寄(mail) → distributionEligible = false          → 不计入辅导员分销
```

**订单表新增字段**：
- `distributionEligible: boolean` — 是否计入分销
- `counselorId?: string` — 关联辅导员（从一人一码Scene参数获取）
- `deliveryType: DeliveryType` — 配送方式

**结算时**：`辅导员提成 = SUM(订单金额 × 提成率) WHERE counselorId=xxx AND distributionEligible=true`
