# 邑夏小程序 - 首页果酒导航区改造

## ⚠️ 铁律：不要用AI生成任何图片！不要修改/删除已有图片文件！只改代码！

---

## 任务目标

将首页原来的**单张Banner链接整个分类**的逻辑，改为**6张果酒产品图横滑区域，每张图点击跳转对应产品详情页**。

---

## 修改文件：src/pages/index/index.tsx

在现有import语句之后，添加：


### 步骤2：定义果酒导航数据（在组件内部、return之前）

```typescript
/** 首页果酒导航区 - 6款果酒，每张图链到对应产品详情 */
const WINE_NAV_ITEMS = [
  { id: 'prod_pomegranate_new', name: '榴红心事', sub: '石榴·7°', price: '¥49.9', image: winePomegranate },
  { id: 'prod_grape_wine',      name: '葡香暗度', sub: '葡萄·7°', price: '¥49.9', image: wineGrape },
```

### 步骤3：添加跳转函数（在组件内部）

```typescript
/** 跳转产品详情页 */
const goToProductDetail = (productId: string) => {
  Taro.navigateTo({ url: `/pages/product/detail?id=${productId}` })
}
```

如果项目已有类似跳转函数，直接复用，不要重复定义。

### 步骤4：替换首页Banner区域为果酒导航区

找到首页JSX中原有的Banner/Swiper区域（通常是 `<Swiper>` 组件或 `bannerList.map` 的部分），将**整个Banner区域**替换为以下代码：

```tsx
{/* ========== 果酒导航区 - 6款果酒横滑 ========== */}
<View className="wine-nav-section">
  <View className="wine-nav-header">
    <View className="wine-nav-title">
      <Text className="wine-nav-title-text">邑夏果酒</Text>
      <Text className="wine-nav-title-sub">7度微醺 · 养生果酒</Text>
    </View>
  </View>
  <ScrollView scrollX className="wine-nav-scroll" enhanced showScrollbar={false}>
    <View className="wine-nav-list">
      {WINE_NAV_ITEMS.map((item) => (
        <View
          key={item.id}
          className="wine-nav-card"
          onClick={() => goToProductDetail(item.id)}
        >
          <View className="wine-nav-img-wrap">
            <Image
              src={item.image}
              className="wine-nav-img"
              mode="aspectFill"
            />
          </View>
          <View className="wine-nav-info">
            <Text className="wine-nav-name">{item.name}</Text>
            <Text className="wine-nav-sub">{item.sub}</Text>
            <Text className="wine-nav-price">{item.price}</Text>
          </View>
        </View>
      ))}
    </View>
  </ScrollView>
</View>
```
