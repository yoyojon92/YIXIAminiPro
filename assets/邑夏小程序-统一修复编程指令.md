## ⛔ 执行铁律（必读，不可压缩不可省略）

以下规则优先级高于一切。违反任何一条即为执行失败。

### 铁律1：禁止说而不做
- **禁止**在回复中说"我已修改了XXX"但实际文件未写入。每声称一个操作，必须真实执行write_file/edit_file/bash写入。
- **禁止**用注释占位符代替实际实现。如 `// TODO`、`/* 待对接API */`、`暂不实现` 均禁止出现。
- **禁止**只改了import但不用、只声明了interface但不实例化、只写了函数签名但函数体是空的。

### 铁律2：禁止上下文压缩导致功能丢失
- 本文档中每一个模块、每一个页面、每一个Store都必须完整实现，不允许因为"篇幅限制"跳过任何一个。
- 如果你觉得输出会超限，应该按模块分步写入文件，而不是把某个模块压缩成"参照上面类似实现"。
- 每个页面的Mock数据必须能渲染出完整UI，不允许出现空白卡片、空列表、占位文字。

### 铁律3：禁止伪完成
- **禁止**创建路由但目标页面不存在。app.config.ts注册了路径，则对应tsx必须真实创建。
- **禁止**修改了profile页面的跳转路径但新路径对应的页面不存在。
- **禁止**在Store中声明了方法但页面不调用、或页面import了Store但Store方法未定义。

### 铁律4：验证清单（执行完必须逐项自检）
每完成一个模块，必须对照以下清单自检并输出结果：
```
[ ] 页面文件已创建且内容完整（非空文件）
[ ] 页面config.ts已创建
[ ] app.config.ts已注册该页面路径
[ ] Store文件已创建且所有声明的方法都有完整实现体
[ ] 页面中import的组件在项目中存在
[ ] 页面中import的Store方法在Store中有定义
[ ] Mock数据足够渲染出完整UI（无空白卡片、无空列表）
[ ] 路由跳转目标页面存在（不会跳到404或错误页面）
[ ] 所有页面的navigationBarTextStyle为'white'
[ ] tabBar页面的跳转使用switchTab，非tabBar页面使用navigateTo
```

### 铁律5：文件粒度操作
- 每个文件单独一次write_file/edit_file调用，不要把多个文件内容拼在一次调用里。
- 修改已有文件时必须先read_file确认当前内容，然后用edit_file精确替换，不要整个文件覆盖。

### 铁律6：tabBar页面禁止使用navigateTo ⚠️新增
- 微信小程序中，**tabBar页面只能用`Taro.switchTab()`跳转，禁止用`navigateTo`或`router.push()`**
- 当前tabBar页面列表（来自app.config.ts）：首页(index)、分类(category)、购物车(cart)、我的(profile)
- **switchTab不支持URL参数**，需要通过全局Store传递参数（如分类ID）
- 非tabBar页面之间可以正常使用navigateTo/router.push传参

## 🔍 逻辑错误根因分析（必读，不可跳过）

### 错误1：首页分类图标点不开 ⚠️最高优先级
**现象**：首页点击"果酒系列"/"粮食酒系列"/"NFC果汁系列"/"礼盒套装"图标，无法跳转到分类页，控制台报错 `navigateTo:fail can not navigateTo a tabbar page`。
**根因**：分类页（category/index）是tabBar页面，但首页代码用了 `router.push({ url: '/pages/category/index?category=fruit_wine' })`，相当于`navigateTo`。微信小程序禁止`navigateTo`跳转tabBar页面，必须用`switchTab`。但`switchTab`不支持URL参数（`?category=fruit_wine`），所以分类ID传不过去。
**修复策略**：
1. 新建`categoryStore.ts`，用Zustand存储用户点击的分类ID
2. 首页点击分类时：先`categoryStore.setSelectedCategory('fruit_wine')`，再`Taro.switchTab({ url: '/pages/category/index' })`
3. 分类页`useDidShow`生命周期中读取`categoryStore.selectedCategory`，据此筛选产品

### 错误2：跑腿员中心两个空白卡片
**根因**：Coze生成了flex容器但跳过了卡片内部内容实现。
**修复策略**：整体重写runner-center页面。

### 错误3：profile页面"支付方式"跳转到订单页面
**根因**：toolItems的path全部指向`/pages/orders/index?tab=xxx`，orders页面只处理了订单tab。
**修复策略**：每个功能独立页面。

### 错误4：跑腿员订单列表为空
**根因**：混淆了"送酒员资料"和"配送订单"两套数据。
**修复策略**：独立的RunnerOrder类型和Mock数据。

### 错误5：开关按钮下无状态说明
**修复策略**：开关左侧加状态圆点+文字。

### 错误6：会员积分/充值卡页面完全不存在
**根因**：路由先行、页面后置。
**修复策略**：先建页面再改路由。

### 错误7：userStore角色与三角色体系不一致
**修复策略**：统一为`'user' | 'agent' | 'super_admin'`。

### 错误8：产品详情页永远显示同一个产品
**根因**：硬编码了productDetail。
**修复策略**：根据URL的id参数动态加载。

### 错误9：产品详情页"配送方式"模块无功能
**修复策略**：直接删除，留到下单结算流程。

### 错误10：深色导航栏/顶部栏文字不可见
**根因**：顶部渐变区域文字用了`text-gray-900`等深色，与深色背景融为一体。
**修复策略**：所有顶部渐变区域内文字必须用`text-white`/`text-white/70`/`text-white/50`。所有config.ts的`navigationBarTextStyle`必须为`'white'`。

### 错误11：支付方式页面应包含充值卡扣款
**根因**：支付方式和充值卡分成两个独立页面，但用户期望统一选择。
**修复策略**：payment页面新增充值卡扣款区块，调用rechargeStore.deduct()。

## 模块一：分类跳转核心修复 ⚠️最高优先级

### 新建 src/store/categoryStore.ts

这是解决"点不开分类页面"的核心。因为category是tabBar页面，switchTab不支持URL参数，所以必须用Store跨页面传递分类ID。

```ts
/**
 * 分类状态管理
 * 用途：从首页点击分类图标时，通过Store传递分类ID到分类页
 * 原因：category是tabBar页面，switchTab不支持URL参数，只能用全局Store传递
 */
import { create } from 'zustand'

export type UnifiedCategoryId = 'fruit_wine' | 'grain_wine' | 'nfc_juice' | 'gift_box'

interface CategoryState {
  /** 用户从首页选择的分类ID，null表示显示全部 */
  selectedCategory: UnifiedCategoryId | null
  /** 设置分类ID（首页点击分类时调用） */
  setSelectedCategory: (categoryId: UnifiedCategoryId | null) => void
  /** 读取并清除分类ID（分类页useDidShow时调用，读完后清空防止下次进入还自动选中） */
  consumeSelectedCategory: () => UnifiedCategoryId | null
}

export const useCategoryStore = create<CategoryState>()((set, get) => ({
  selectedCategory: null,

  setSelectedCategory: (categoryId) => {
    set({ selectedCategory: categoryId })
  },

  consumeSelectedCategory: () => {
    const { selectedCategory } = get()
    set({ selectedCategory: null }) // 读完后清空
    return selectedCategory
  }
}))
```

## 模块四：分类页重写 ⚠️核心修复

### 重写 src/pages/category/index.tsx

**操作前必须先read_file确认当前内容，然后write_file整体重写。**

关键修改：
1. **使用`useDidShow`生命周期**读取Store中的分类ID（不是useEffect，因为tabBar页面每次显示都会触发useDidShow）
2. **调用`consumeSelectedCategory`**（读取后自动清空，防止下次进入还自动选中）
3. **使用统一分类**筛选产品

```tsx
import { useState } from 'react'
import { View, Text, ScrollView } from '@tarojs/components'
import { useRouter } from '@tarojs/taro'
import { useDidShow } from '@tarojs/taro'
import { Card, CardContent } from '@/components/ui/card'
import { UNIFIED_CATEGORIES, UnifiedCategoryId, useCategoryStore } from '@/store/categoryStore'
import { MOCK_PRODUCTS, Product } from '@/mock/products'

export default function Category() {
  const router = useRouter()
  const [selectedCategory, setSelectedCategory] = useState<UnifiedCategoryId | 'all'>('all')
  
  // ⚠️ 核心：每次页面显示时，读取Store中首页传来的分类ID
  useDidShow(() => {
    const categoryFromHome = useCategoryStore.getState().consumeSelectedCategory()
    if (categoryFromHome) {
      setSelectedCategory(categoryFromHome)
    }
  })

  const categories = [
    { id: 'all' as const, name: '全部', icon: '🏠' },
    ...UNIFIED_CATEGORIES.map(cat => ({ id: cat.id as UnifiedCategoryId, name: cat.name, icon: cat.icon }))
  ]
  
  const filteredProducts = MOCK_PRODUCTS.filter(product => {
    if (selectedCategory === 'all') return true
    return product.category === selectedCategory
  })

  // 点击产品跳转到详情页（产品详情页不是tabBar页面，可以用router.push）
  const handleProductClick = (productId: string) => {
    router.push({ url: `/pages/product/index?id=${productId}` })
  }

  return (
    <View className="min-h-screen bg-gray-50 pb-safe">
      {/* 分类标签 */}
      <View className="flex overflow-x-auto bg-white px-2 py-3 gap-1">
        {categories.map(cat => (
          <View
            key={cat.id}
            className={`flex-shrink-0 px-4 py-2 rounded-full text-sm ${
              selectedCategory === cat.id ? 'bg-purple-600 text-white' : 'bg-gray-100 text-gray-700'
            }`}
            onClick={() => setSelectedCategory(cat.id)}
          >
            <Text>{cat.icon} {cat.name}</Text>
          </View>
        ))}
      </View>

      {/* 产品列表 */}
      <ScrollView className="px-4 py-3" scrollY style={{ height: 'calc(100vh - 120px)' }}>
        {filteredProducts.length === 0 ? (
          <View className="flex flex-col items-center justify-center py-20">
            <Text className="text-gray-400">暂无产品</Text>
          </View>
        ) : (
          <View className="grid grid-cols-2 gap-3">
            {filteredProducts.map(product => (
              <Card key={product.id} className="overflow-hidden" onClick={() => handleProductClick(product.id)}>
                <View className="aspect-square bg-gray-100">
                  <Image src={product.image} mode="aspectFill" className="w-full h-full" />
                </View>
                <CardContent className="p-3">
                  <Text className="text-sm font-medium text-gray-900 line-clamp-2">{product.name}</Text>
                  <View className="flex items-baseline gap-2 mt-1">
                    <Text className="text-lg font-bold text-red-500">¥{product.price}</Text>
                    {product.originalPrice > product.price && (
                      <Text className="text-xs text-gray-400 line-through">¥{product.originalPrice}</Text>
                    )}
                  </View>
                  {product.tags && product.tags.length > 0 && (
                    <View className="flex flex-wrap gap-1 mt-1">
                      {product.tags.slice(0, 2).map((tag, idx) => (
                        <Badge key={idx} className="text-xs bg-purple-50 text-purple-600 border-0">{tag}</Badge>
                      ))}
                    </View>
                  )}
                </CardContent>
```

```ts
/**
 * 支付方式状态管理
 * 支持银行卡/支付宝/微信支付/充值卡扣款，默认支付方式切换

  id: string; cardNo: string; balance: number; discount: number; isDefault: boolean
}
export interface PaymentMethod {
  id: string; type: PaymentMethodType; label: string; icon: string
  detail: string; isDefault: boolean; data: BankCard | AlipayAccount | WechatPay | RechargeCardPay
}

interface PaymentState {
  methods: PaymentMethod[]
  defaultMethodId: string | null
  addBankCard: (card: Omit<BankCard, 'id' | 'isDefault'>) => void
  removeMethod: (id: string) => void
  setDefault: (id: string) => void
  addAlipay: (account: Omit<AlipayAccount, 'id' | 'isDefault'>) => void
  syncRechargeCard: (cardId: string, cardNo: string, balance: number, discount: number) => void
  getDefaultMethod: () => PaymentMethod | undefined
}

const BANK_ICONS: Record<string, string> = {
  '工商银行': '🏦', '建设银行': '🏛️', '农业银行': '🌾', '中国银行': '🇨🇳',

}
const generateId = () => `pm_${Date.now()}_${Math.random().toString(36).substr(2, 6)}`

export const usePaymentStore = create<PaymentState>()(
  persist(
    (set, get) => ({
      methods: [{
        id: 'pm_wechat_default', type: 'wechat', label: '微信支付', icon: '💚',
        detail: '微信自动绑定', isDefault: true,

          detail: `**** **** **** ${card.cardNo.slice(-4)}`, isDefault: false,
          data: { ...card, id: generateId(), isDefault: false }
        }
        set(state => ({ methods: [...state.methods, newMethod] }))

          id: generateId(), type: 'alipay', label: '支付宝', icon: '🔵',
          detail: account.account.replace(/(.{3}).*(@.*)/, '$1****$2'),
          isDefault: false,
          data: { ...account, id: generateId(), isDefault: false }
        }
        set(state => ({ methods: [...state.methods, newMethod] }))
      },

      syncRechargeCard: (cardId, cardNo, balance, discount) => {
        set(state => {
          const methods = state.methods.filter(m => m.type !== 'recharge_card')
          const newMethod: PaymentMethod = {
            id: `pm_rc_${cardId}`, type: 'recharge_card', label: '充值卡', icon: '🧧',

          return { methods: [...methods, newMethod] }
        })

          const methods = state.methods.filter(m => m.id !== id)

          }
          return { methods }
        })
      },

      setDefault: (id) => {
        set(state => ({
          defaultMethodId: id,
          methods: state.methods.map(m => ({ ...m, isDefault: m.id === id }))
        }))
      },

      getDefaultMethod: () => get().methods.find(m => m.id === get().defaultMethodId)
    }),
    { name: 'yixia-payment-storage', partialize: (state) => ({ methods: state.methods, defaultMethodId: state.defaultMethodId }) }
  )
```

```ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'
import taroStorage from './taroStorage'

export interface RechargeCard {
  id: string; cardNo: string; balance: number; initialAmount: number
  discount: number; source: string; expireAt: string; isDefault: boolean
}
export interface RechargeRecord {
  id: string; cardId: string; type: 'topup' | 'spend' | 'refund'
  amount: number; balance: number; description: string; createdAt: string
}

interface RechargeState {
  cards: RechargeCard[]; records: RechargeRecord[]
  bindCard: (cardNo: string, amount: number, discount: number, source: string, expireAt: string) => void
  removeCard: (id: string) => void
  setDefault: (id: string) => void
  deduct: (cardId: string, amount: number, description: string) => boolean
  getTotalBalance: () => number
}

const generateId = () => `rc_${Date.now()}_${Math.random().toString(36).substr(2, 6)}`

export const useRechargeStore = create<RechargeState>()(
  persist(
    (set, get) => ({
      cards: [{ id: 'rc_init_1', cardNo: 'YX2026****8888', balance: 350, initialAmount: 500, discount: 0.9, source: '邑夏开学季充值卡', expireAt: '2027-03-01', isDefault: true }],
      records: [
        { id: 'rr_1', cardId: 'rc_init_1', type: 'topup', amount: 500, balance: 500, description: '充值', createdAt: '2026-03-01 10:00' },
        { id: 'rr_2', cardId: 'rc_init_1', type: 'spend', amount: 85, balance: 415, description: '购买蜜桃果酒x2', createdAt: '2026-04-05 14:30' },
        { id: 'rr_3', cardId: 'rc_init_1', type: 'spend', amount: 65, balance: 350, description: '购买石榴果酒x1+配送', createdAt: '2026-05-10 20:15' }
      ],
      bindCard: (cardNo, amount, discount, source, expireAt) => {
        const newCard: RechargeCard = { id: generateId(), cardNo, balance: amount, initialAmount: amount, discount, source, expireAt, isDefault: get().cards.length === 0 }
        set(state => ({ cards: [...state.cards, newCard], records: [{ id: generateId(), cardId: newCard.id, type: 'topup' as const, amount, balance: amount, description: `绑定充值卡 ${cardNo}`, createdAt: new Date().toLocaleString('zh-CN') }, ...state.records] }))
      },
      removeCard: (id) => { set(state => { const cards = state.cards.filter(c => c.id !== id); if (state.cards.find(c => c.id === id)?.isDefault && cards.length > 0) cards[0].isDefault = true; return { cards } }) },
      setDefault: (id) => { set(state => ({ cards: state.cards.map(c => ({ ...c, isDefault: c.id === id })) })) },
      deduct: (cardId, amount, description) => {
        const card = get().cards.find(c => c.id === cardId)
        if (!card || card.balance < amount) return false
        const discountedAmount = Math.round(amount * card.discount * 100) / 100
        set(state => ({
          cards: state.cards.map(c => c.id === cardId ? { ...c, balance: Math.round((c.balance - discountedAmount) * 100) / 100 } : c),
          records: [{ id: generateId(), cardId, type: 'spend' as const, amount: discountedAmount, balance: Math.round((card.balance - discountedAmount) * 100) / 100, description: `${description}（${(card.discount * 10).toFixed(0)}折）`, createdAt: new Date().toLocaleString('zh-CN') }, ...state.records]
        }))
        return true
      },
      getTotalBalance: () => get().cards.reduce((sum, c) => sum + c.balance, 0)
```
