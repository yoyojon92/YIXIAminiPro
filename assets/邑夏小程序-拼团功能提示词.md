## 修改文件3：src/pages/product/detail.tsx

### 3.1 识别拼团入口

在详情页的 `useRouter` 或 `useSearchParams` 中读取 `pintuan` 参数：

```typescript
const params = Taro.getCurrentInstance().router?.params
const isPintuan = params?.pintuan === 'true'
```

### 3.2 拼团价格展示

如果 `isPintuan=true`，价格区域显示拼团价：

```tsx
{isPintuan ? (
  <View className="price-area">
    <Text className="pintuan-price">¥39.9</Text>
    <Text className="original-price-line">¥49.9</Text>
    <View className="pintuan-badge">2人拼团价</View>
  </View>
) : (
  // 原价展示逻辑保持不变
)}
```

### 3.3 底部按钮改为拼团操作

如果 `isPintuan=true`，底部操作按钮改为：

```tsx
{isPintuan ? (
  <View className="pintuan-action-bar">
    <View className="pintuan-btn" onClick={handlePintuan}>
      <Text className="pintuan-btn-text">邀请好友拼团</Text>
      <Text className="pintuan-btn-sub">2人成团·¥39.9/人</Text>
    </View>
  </View>
) : (
  // 原来的"加入购物车"等按钮
)}
```

### 3.4 拼团发起逻辑（前端交互）

```typescript
const handlePintuan = () => {
  // 拼团逻辑：当前为Mock阶段，使用微信分享
  Taro.showModal({
    title: '邀请好友拼团',
    content: '分享给好友，2人成团即可享受¥39.9拼团价（原价¥49.9，立减¥10）',
    confirmText: '去分享',
    success: (res) => {
      if (res.confirm) {
        // 触发微信分享
        Taro.showShareMenu({
          withShareTicket: true,
          menus: ['shareAppMessage', 'shareTimeline']
        })
      }
    }
  })
}
```

同时确保页面配置了分享：

```typescript
// 在页面配置中开启分享
Taro.useShareAppMessage(() => {
  return {
    title: `邑夏${productName}拼团，2人成团仅¥39.9，立减¥10！`,
    path: `/pages/product/detail?id=${productId}&pintuan=true`,
    imageUrl: productImage
  }
})
```
