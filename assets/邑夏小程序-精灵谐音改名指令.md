# 邑夏小程序 - 精灵谐音改名指令

## 任务目标
将小程序中所有器官重复字角色名改为谐音字，去除"器官"感，更符合女孩IP定位。

## 替换规则
| 原名 | 新名 | 说明 |
|------|------|------|
| 心心 | 欣欣 | 心→欣，欢欣之意 |
| 肝肝 | 甘甘 | 肝→甘，甜蜜之意 |
| 肺肺 | 霏霏 | 肺→霏，飘霏之美 |
| 肾肾 | 沈沈 | 肾→沈，深沉之意 |
| 脾脾 | 皮皮 | 脾→皮，俏皮之意 |

**注意：** 只替换"心心/肝肝/肺肺/肾肾/脾脾"这种双字重复的角色名，不替换单字（如focusOrgan:'心'保持不变），不替换非角色名的器官词（如"脾胃食堂"保持不变）。

## 高效执行方式（推荐sed批量替换）

在项目根目录执行以下命令，一次性完成所有替换：

```bash
cd /workspace/projects

# 全局批量替换（按顺序执行，避免冲突）
find src/ -name "*.ts" -o -name "*.tsx" | xargs sed -i \
  -e "s/心心/欣欣/g" \
  -e "s/肝肝/甘甘/g" \
  -e "s/肺肺/霏霏/g" \
  -e "s/肾肾/沈沈/g" \
  -e "s/脾脾/皮皮/g" \
  -e "s/脾宝/皮宝/g" \
  -e "s/小脾脾/小皮皮/g"

# 验证：确认无残留
grep -rn "心心\|肝肝\|肺肺\|肾肾\|脾脾\|脾宝\|小脾脾" src/ --include="*.ts" --include="*.tsx"

# 构建
pnpm validate && pnpm build:weapp

# 提交
git add -A && git commit -m "refactor: 精灵谐音改名 心心→欣欣 肝肝→甘甘 肺肺→霏霏 肾肾→沈沈 脾脾→皮皮" && git push
```
