## 关键约束（不可违反）

1. **微信主包限制1.5MB**，所有产品图片压缩后总大小需控制在1MB以内
2. **单张图片≤200KB**（微信代码质量扫描要求）
3. **tabbar图标保留本地**（<10KB，微信要求）
4. **图片文件名只用英文+数字+短横线**，严禁中文文件名（Windows git pull会报错）
5. **Coze不要动图片文件本身**——压缩操作在沙箱用bash/sharp完成，不要用write_file写二进制
6. **jsDelivr不支持图片处理参数**（?w=400被忽略，已验证）
7. **AI图片合规**：保留"豆包AI生成"水印，详情页必须加免责声明"部分图片为AI辅助生成，实物以实拍为准"
8. **Taro必须配copy.patterns**否则图片不到dist
9. **PowerShell Set-Content会破坏UTF-8编码导致中文乱码**，必须用[System.IO.File]::WriteAllText + UTF8Encoding($false)
10. **给Coze指令必须给最终态数据整段替换**，不要逐步修改描述

## 压缩脚本示例（沙箱执行）

```bash
# 安装sharp-cli
npm install -g sharp-cli

# 批量压缩PNG到WebP（质量80，宽度≤800px）
for f in src/assets/images/products/**/*.png; do
  sharp -i "$f" -o "${f%.png}.webp" resize 800 webp quality 80
  # 更新products.ts中的引用 .png → .webp
done

# 或者用imagemagick
apt-get install -y imagemagick
for f in src/assets/images/products/**/*.png; do
  convert "$f" -quality 85 -resize '800x800>' "${f%.png}.webp"
done
```
